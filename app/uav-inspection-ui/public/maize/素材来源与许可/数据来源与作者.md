# 来源与许可记录

1. MaizeField3D：Iowa State University，Elvis Kimara、Mozhgan Hadadi 等。官方项目 https://baskargroup.github.io/MaizeField3D/ ，数据 https://huggingface.co/datasets/BGLab/MaizeField3D 。沿用 CC BY-NC 4.0 几何；下载元数据见 metadata/maize_repository.json、maize_files.json。正式叶片直接保留官方 STL 顶点及三角面；DAT 用于编号和 UV 匹配。
2. PlantSeg：Tianqi Wei、Zhi Chen、Xin Yu、Scott Chapman、Paul Melloy、Zi Huang。仓库 https://github.com/tqwei05/PlantSeg ，本项目所用发布版本 https://zenodo.org/records/14935094 。API 快照 downloads/plantseg_zenodo_v5.txt 中 metadata.license.id 为 cc-by-4.0。不要把后续论文页面许可自动当作该 v5 数据发布许可。原始图片/标注来自该版子集；原图 SHA、原始类别、官方掩码 SHA 和裁剪记录逐项保留。发布许可不等于本项目独立核验了每张网络原图的第三方权利。
3. PlantVillage：Sharada P. Mohanty、David P. Hughes、Marcel Salathé。官方仓库 https://github.com/spMohanty/PlantVillage-Dataset ，作者数据卡 https://huggingface.co/datasets/mohanty/PlantVillage 。数据卡 CC BY-SA 3.0 快照在 downloads/plantvillage_card.txt。96 张 Common_rust 真实照片逐张验证官方 Git blob SHA1，记录于 metadata/rust_source_images.json；保留来源 URL、SHA256。61 个正式纹理来自这些照片，掩码为本项目颜色规则弱分割，不是官方病斑分割。
4. 叶位先验沿用 V1 的公开来源：Cornell https://cals.cornell.edu/field-crops/corn/diseases-of-corn/gray-leaf-spot 、https://cals.cornell.edu/field-crops/corn/diseases-of-corn/northern-corn-leaf-blight 、https://cals.cornell.edu/field-crops/corn/diseases-of-corn/common-rust 。数字概率、阶段与数量为模拟参数，不是实测发生率。
5. 远端环境参考 https://github.com/johnnylu305/Hestia-NBV 。适配目标 Isaac Sim 4.5.0 / Isaac Lab 2.1；实际用户主机需自行运行脚本记录版本。
