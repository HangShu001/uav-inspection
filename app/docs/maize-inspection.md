# 玉米单株与密植巡检模块

平台首页「病虫害巡检」仍进入 `/pest`，沿用平台账号登录。模块内容替换为
用户提供的「玉米巡检_单株与密植_离线分发包」，通过同源 iframe 隔离原演示的
全局 CSS 和 Three.js，避免与平台其他模块冲突。上方提供返回平台和全屏按钮。

## 功能与数据

- 单株、两株密植、三株密植，共三个场景。
- 自主视点、固定环绕、上方蛇形，共九组已完成的仿真巡检记录。
- 开始、暂停、重新开始、进度拖动、倍速、植株聚焦和相机放大。
- 原始照片、检测标记、飞行轨迹、观察范围、病斑标记。
- 覆盖率、病斑检出率、误报比例、航程、各株覆盖情况及三种结果对比。
- 当前记录与对比结果的 JSON 下载。

这是仿真记录的交互回放；浏览器不重新训练、推理或规划，不连接真实无人机。
结果不能视作真实田间诊断。原始九组数据与全部计算逻辑保持原样。

## 部署

资源位于 `uav-inspection-ui/public/maize/`，Vite 构建自动原样复制到
`dist/maize/`。现有 Docker 构建和 FastAPI 静态文件托管无需新增服务；
源码交付脚本也会将本目录完整的 HTML、JS、说明、许可和核验 JSON 放入应用包。
本模块不依赖 `02-data`、推理环境或原病虫害后端接口。

根路径部署使用 `/maize/index.html`；`VITE_BASE=/uav/` 构建后使用
`/uav/maize/index.html`，内部桥接脚本使用相对路径。平台原有账号服务仍须启动。
首次打开约需传输 71 MB 的页面、脚本与场景数据，建议配置服务器传输压缩并等待加载完成。
需要支持 WebGL 的新版 Chrome / Edge，建议桌面使用；窄屏通过独立的
`platform-layout.css` 将控制、场景和结果面板纵向排列。

`platform-bridge.js` 仅监听原演示的加载遮罩，并向同源父页面通知就绪或失败。
平台检查消息来源及 iframe 窗口，只有素材与 WebGL 就绪才撤掉加载提示。
加载失败提供重试及独立窗口入口；离开 `/pest` 时 iframe 和场景随页面卸载。
为避免无需推理依赖的演示被无关部署提示覆盖，本页面使用自己的加载状态提示。

## 原包追溯与许可

`offline_package_manifest.json`、`evidence.json`、`核验记录/` 为原包随附资料，
其中的历史核验结论属于原包作者记录。公开版本的 `evidence.json` 将本机绝对路径
规范化为 `assets/` 下的素材相对路径，校验值保持原样。
原始 HTML 为 70,857,925 字节，SHA-256：
`c65f2473a7511e5044fa667fc5abfe464d5a44534126511399c98181bfa42596`。
为适配上传限制，原 HTML 的数据与执行脚本拆分为 `data.js`、`scene-N-part-XX.js`
和 `app.js`。场景分块按顺序拼接成原始 JSON 后装入原数据对象，并释放临时字符串；
执行顺序保持不变，分块兼容直接双击打开，不依赖网络服务。
另外增加 `platform-bridge.js` 的状态通知和 `platform-layout.css` 的窄屏布局。
完整性测试移除这两个集成标签、重新合并全部原始内容分块后，验证字节数及 SHA-256
与原包完全一致，确保没有改写回放逻辑、照片、几何或指标。

保留 `素材来源与许可/` 中全部文件及 HTML 内嵌署名、许可与纹理变换记录。
几何素材适用 CC BY-NC 4.0，纹理分别适用 CC BY 4.0 / CC BY-SA 3.0，
不得将整个素材包统一标为 MIT。详见随包「数据许可.md」与「数据来源与作者.md」。

## 验证

```sh
cd uav-inspection-ui
npm ci
npm run build
node --test tests/*.test.mjs
```

从 `app/` 执行 `python -m unittest discover -s tests` 检查源码分发与原包完整性。
人工验收应包含登录后打开 `/pest`、九种场景/方式组合、播放暂停与进度拖动、
对比表、JSON 导出、返回平台、重新进入及 `/uav/` 子路径部署。

本次本地验证结果见 [maize-verification.json](maize-verification.json)：九组回放指标、
两种部署路径、暂停与进度拖动、相机放大、对比导出、返回重进、刷新、390 px 窄屏及缺失资源重试通过。
平台账号接口使用本地测试响应，未连接生产账号服务；本次验证未执行服务器部署。
