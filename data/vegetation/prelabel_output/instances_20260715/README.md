## 审核重点

- 同一棵树出现多种颜色：需要合并实例。
- 多棵树共用一种颜色：需要拆分实例。
- 玫瑰园1号地候选数较多，应优先检查过分割。
- `tree_instances.csv` 保存每个实例的点数、坐标范围和 P99 离地高度。
- `tree_instances_overview.png` 是俯视彩色预览。

这些文件与 WebODM 和原始 LAZ 完全分离，可直接在 CloudCompare 中修改或另存。
