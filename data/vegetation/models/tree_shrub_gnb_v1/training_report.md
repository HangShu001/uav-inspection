# 乔木/灌木轻量模型 V1

模型：对角高斯朴素贝叶斯。特征使用 RGB 派生量和局部离地高度，不使用绝对坐标。

## 数据划分

- 训练：树 ID 1～7、灌木 ID 1、空间训练区背景。
- 验证：树 ID 8～10、灌木 ID 2、空间留出背景。

## 验证结果

- Accuracy：0.743
- Macro F1：0.752

| 类别 | Precision | Recall | F1 | 验证点数 |
|---|---:|---:|---:|---:|
| 其他 | 0.687 | 0.699 | 0.693 | 60,000 |
| 乔木 | 0.755 | 0.699 | 0.726 | 60,000 |
| 灌木 | 0.805 | 0.869 | 0.836 | 42,359 |

## 限制

人工真值只有 10 棵树和 2 片灌木，尤其灌木验证只来自一个实例。该模型是流程基线，不能代表跨园区泛化能力。
